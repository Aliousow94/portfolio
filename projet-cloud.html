TP Cloud Computing & Virtualisation — sous la direction du Pr. Dr Lamine YADE

Virtualisation & administration réseau (TP2-TP3)

  • Gestion du stockage Linux : partitionnement avec parted, tables GPT, formatage ext4, labels de volume
  • Persistance système : configuration avancée de /etc/fstab avec UUID et option nofail (montage pérenne au boot)
  • Réseaux isolés : architecture double sous VirtualBox — NAT avec redirection de ports + Host-Only pour les flux privés
  • Sécurisation SSH : installation et durcissement du démon sshd (port TCP/22), filtrage et validation avec ss

Conteneurisation & micro-services (TP4-TP6)

  • Cycle de vie des conteneurs : industrialisation d'applications web (Nginx Alpine), gestion des statuts (Up, Exited), traçabilité (journalctl, docker stats)
  • Industrialisation par le code : Dockerfile documenté et optimisé (.dockerignore, sondes HEALTHCHECK)
  • Immuabilité des couches : validation du cache de build et empreintes cryptographiques SHA-256
  • Persistance & DNS embarqué : réseau bridge utilisateur (campus-net) avec résolution de noms entre conteneurs, volumes nommés découplant données et cycle de vie des instances

🎓 Ce que ce projet m'a apporté

  • Administration système Linux en environnement serveur
  • Conception d'architectures réseau virtualisées et isolées
  • Maîtrise de Docker au-delà du simple usage : Dockerfile, réseaux, volumes, supervision
