Java · Application desktop

Plateforme de vote électronique

Application souveraine et sécurisée pour les scrutins internes de l'UAM (délégués, chefs de département, directeurs d'UFR)

Java 17JavaFXFXML MySQLJDBCMavenMVC

Projet final — UE Java Avancé, L3 Informatique (UAM)
Encadrants : Pr Amadou Dahirou GUEYE · Dr Lamine YADE

Fonctionnalités clés

  • Architecture robuste : pattern MVC découplant logique métier et affichage
  • Sécurité & anti-fraude : hachage des mots de passe (SHA-256), authentification par rôles, contraintes d'unicité SQL empêchant le double vote
  • Ciblage dynamique : filtrage automatique des scrutins selon le profil de l'électeur (UFR, Département, Classe)
  • Tableau de bord admin : statistiques en temps réel avec visualisations JavaFX (BarChart, PieChart)
  • Bonus : importation d'électeurs en masse (CSV) et génération de cartes d'électeurs / rapports de dépouillement PDF (iText)

🎓 Ce que ce projet m'a apporté

  • Conception d'une architecture logicielle complète (MVC, couches)
  • Gestion de la persistance avec MySQL/JDBC
  • Bonnes pratiques de sécurité applicative (hachage, rôles, contraintes SQL)
  • Développement d'une interface riche avec JavaFX/Scene Builder
